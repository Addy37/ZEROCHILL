# ZEROCHILL 5.4.0

Faster Search, improved Shows, Bunkr playback fixes, XMegaDrive improvements, and a clearer update experience.

- Reworked the Shows watch experience with smoother YouTube-style open and Back motion, large related thumbnails, improved landscape controls, and a five-second Up Next countdown.
- Improved large Shows collections with cleaner episode presentation, 10-item browsing, range navigation, background prefetching, resume/progress state, and cinematic category heroes.
- Fixed Bunkr playback and artwork edge cases, refreshed expired signed media links, and added native Bunkr album Search.
- Filtered XMegaDrive premium-only videos so Search, categories, and ShitTok candidates stay focused on content that can actually play in ZEROCHILL.
- Made global Search feel faster across Shows, OnlyFap, Bunkr, XMegaDrive, BaddieHub, and Library with quicker first results, safer caching, and progressive result loading.
- Update prompts now show a concise What’s New summary from the release notes instead of only the generic release name.
- Existing accounts, favorites, history, downloads, messages, settings, and other saved data are preserved when updating.

Install over your existing ZeroChill app without uninstalling.
