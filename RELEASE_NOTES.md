# ZEROCHILL 7.5.1

Better previews. Smarter search.

- Pawchive improvements: Restored missing videos in mixed galleries.
- Better video thumbnails: Automatic previews with faster loading.
- Smarter Spotlight: Search across all creator sources regardless of your selected preference.

## A note about Pawchive

Pawchive doesn't provide video thumbnails. ZEROCHILL generates them from each video while respecting server request limits. Previews may take longer to appear, but normal playback is unaffected.

## Updating

Install **ZeroChill.apk** over your existing ZEROCHILL installation to keep your saved data and settings. Version 7.5.1 uses Android version code `7005100`.

[Compare the changes since 7.5.0](https://github.com/Addy37/ZEROCHILL/compare/v7.5.0...v7.5.1)
