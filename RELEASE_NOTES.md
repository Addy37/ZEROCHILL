# ZeroChill 4.0.0

ZeroChill 4.0.0 is a major refresh of the app's navigation, Shows, OnlyFap, Library, playback, and visual system.

- ShitTok remains the main landing tab. Home is removed from the visible bottom navigation, and Library is now a primary destination.
- Shows now opens into a combined cinematic hub with a full-bleed rotating hero, fresh weekly content, improved collection screens, immersive playback, and Continue Watching with captured video frames.
- OnlyFap has been rebuilt as a creator discovery hub with a large portrait-first rotating hero, Trending, New Creators, Hot, Popular, Favorite Creators, faster creator loading, and direct gallery access.
- Library is now a visual media hub for Continue Watching, Watch Later, History, Downloads, and Favorite Creators, with local search across the full Library views.
- The bottom navigation now collapses while you browse, keeping the ZEROCHILL glass treatment while giving content more screen space.
- Search and More controls are cleaner. More is now a compact top-right menu with Downloads, Settings, Account, and Send feedback.
- Player controls, playback transitions, loading animation, fullscreen behavior, and resume handling have received a major polish pass.
- Thumbnail borders have been removed app-wide for a cleaner media-first look.
- Main section titles now use the larger ZEROCHILL white and electric-blue treatment.
- Settings has been simplified by removing obsolete controls. Playback resume remains enabled automatically.
- Existing installs keep the same application ID, signing identity, favorites, history, Watch Later, downloads, backups, and other persisted data.

This release supports an in-place upgrade from ZeroChill 3.1.6.
