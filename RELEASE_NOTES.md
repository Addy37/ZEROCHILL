# ZEROCHILL 7.2.0

Cleaner comments and smoother Search, automatic Shows rotation, episodic Bunkr albums, easier DM links and copying, and clearer ShitTok videos.

## What's new

- Comments stay in place. Type directly above the keyboard and enjoy a cleaner header.
- Shows rotates naturally. Turn your phone with Auto Rotate enabled, or use manual fullscreen when rotation is locked.
- Bunkr albums play like series. Browse numbered videos and episode ranges, with next-video playback in album order. Images stay separate, and cleaner titles keep original filenames available.
- DMs are easier to use. Tap web links to open or copy them, and long-press a text message for a clear Copy message action.
- ShitTok keeps the video clear. The broad dark gradient is gone, with outlined, shadowed text keeping titles readable.
- Search arrives smoothly. Results fade and gently settle into place without delaying cached or live results.

## Updating

Download **ZeroChill.apk** and install it over your current ZEROCHILL app. Do not uninstall the app or clear its data first. Your favorites, downloads, watch history, settings and backups remain available with a normal in-place update.

Version 7.2.0 (Android versionCode 7002000) upgrades production 7.1.0 and the three 7.1.1 test APKs, including code 7001003. The application ID and production signing certificate are unchanged.

## Compatibility

Content sources, authentication and New Zerochill backend routing are preserved. No backend deployment or user-data migration is part of this release. Existing ShitTok sharing, replay and Focus Mode improvements remain included.

The update dialog uses this release's opening summary. The installed What's New popup contains the same six highlights above and remains available from Settings.
