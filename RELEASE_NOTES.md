# ZeroChill 4.3.5

- Added BaddieHub portrait videos to normal ShitTok refills while keeping existing sources available.
- Added native BaddieHub Categories to Shows with category browsing, playback, history, and resume support.
- Improved ShitTok source diversity and portrait-first selection so the feed stays varied without changing existing preload or playback behavior.
- Added **Block creator from ShitTok** for supported creator-resolvable clips, plus a Settings → Playback screen for reviewing and unblocking creators.
- Updated BaddieHub video detail playback so related videos come from BaddieHub instead of falling back to another source.
- Fixed BaddieHub landscape fullscreen controls so the HUD auto-hides correctly during playback.
- Added remote-source configuration support for BaddieHub with bundled known-good fallbacks for older remote payloads.
- Stability fixes and regression coverage for ShitTok queue handling, Shows playback, source routing, and BaddieHub parsing.
