## 😈 What is ZEROCHILL?

ZEROCHILL puts supported media sources into one Android app so you can browse, watch, save, search, and come back to content without jumping between separate sites.

It is built around native Android UI, Media3 playback, quick source handling, fast creator galleries, and a feed-first experience.

## 🚀 Built to keep moving

ZEROCHILL is tuned around quick native browsing and playback instead of sending every action through a web page.

- **Feed preloading** prepares upcoming ShitTok video before you swipe.
- **Fast source failover** moves past slow or unavailable hosts where supported.
- **Progressive creator galleries** show usable results while deeper media continues loading.
- **Warm media loading** prepares nearby gallery items ahead of time.
- **Native playback** keeps video in the app with resume and fullscreen controls.
- **Source-aware routing** keeps related content attached to the correct provider where supported.

Source availability can change without notice because ZEROCHILL depends on third-party services.

Install the signed ZEROCHILL APK directly over your existing stable installation.

**Do not uninstall the old app first.**

ZEROCHILL keeps the same Android application ID and signing identity for upgrade compatibility. Android treats the new APK as an update and retains compatible app data, favorites, history, downloads, and settings.

The `.dev` debug package installs separately and does not update stable installs.

## 🔌 Content and sources

ZEROCHILL is an independent native client for supported third-party sources. It does not bundle their media.

A source can change, slow down, block a region, or go offline. ZEROCHILL keeps known-good local behavior and source-specific handling to reduce the impact when one provider has problems.

## 🔒 Privacy

ZEROCHILL sends aggregate usage events to its project service, including app opens, version, section, source, and creator interest.

It uses rotating hashed keys for daily, weekly, and monthly counts. Optional feedback sends the details you submit plus device and app context.

Read **[PRIVACY.md](PRIVACY.md)** for the full description of what the app sends and stores locally.

## ⚖️ Rights and ownership

ZEROCHILL is an independent community client. It is not affiliated with or endorsed by connected websites.

Their content and branding belong to their respective owners. The app does not bundle their media or bypass access controls.

<summary><strong>🛠️ Build from source</strong></summary>

<br>

Current ZEROCHILL development uses **`rebrand/zerochill`** as the source-of-truth branch until it is merged into `main`.

Use:

- Java 17
- Gradle 8.7
- Android SDK 35

The main Android module is `app`. The private feedback and analytics companion is `feedbackadmin`.

```bash
gradle --no-daemon :app:testDebugUnitTest :app:testReleaseUnitTest :app:assembleDebug :app:assembleRelease
gradle --no-daemon :feedbackadmin:assembleRelease
```

Local release builds need the private signing variables described in **[SIGNING.md](SIGNING.md)**.

Unsigned or debug-signed builds cannot update stable installations. Production APKs are built and verified by the repository release workflow. No signing keys or admin tokens belong in the repository.
