## Built for native playback

The Android player uses Media3 / ExoPlayer rather than relying entirely on embedded web players.

- **Playback controls:** fullscreen, resume, seeking, speed and picture-in-picture where supported.
- **Feed continuity:** nearby videos can prepare ahead, while independent feeds retain their playback position.
- **Gallery loading:** bounded thumbnail preparation keeps new results arriving in batches.
- **Source-aware media:** preserve album and creator context when returning to saved items where supported.
- **Downloads:** save supported media through the app and manage downloads from Library or More.

Performance and media compatibility depend on the device, network and connected source. Some formats or unavailable streams may require an alternative supported playback path.

Tap the bookmark in ShitTok or Shows to choose **Watch Later** or **Add to collection**. Existing collection and gallery tools remain available in Library.

### Updating an existing installation

> [!IMPORTANT]
> **Do not uninstall your current stable installation before updating.**

Install the new signed APK directly over your existing ZEROCHILL or compatible legacy CrazyShit installation. The production application ID and signing identity remain the same to preserve upgrade compatibility and compatible local data.

The in-app update prompt also links to the published release. Use the normal Android installer to complete the update.

For extra protection, create a local backup before updating. A debug or side-by-side `.dev` build is a separate package and does not replace the stable app.

## Sources and availability

ZEROCHILL is an independent client that loads supported third-party media at runtime. It does not bundle the connected websites' content.

Sources can change their pages, restrict access by region, limit requests, or go offline. The app uses source-specific handling and remote configuration with bundled fallbacks to respond to ordinary source changes where supported. A working app cannot guarantee that every external source or stream will be available.

- Report app navigation, playback, download and interface issues to ZEROCHILL.
- Direct questions about website accounts, hosted content or takedowns to the relevant website.

## Frequently asked questions

<details>
<summary><strong>Will an update erase my favorites or downloads?</strong></summary>

Install the official signed update over the existing compatible stable installation. The app retains its production package and signing identity. Compatible data is intended to survive the update. Uninstalling or clearing app storage can erase local data, so make a backup before major updates.

</details>

<details>
<summary><strong>Why does a source show no results or a video fail to load?</strong></summary>

The connected service may be unavailable, restricted in your region, or returning an unsupported media format. Try again later or use another available source. Include the affected source and device details when reporting an app issue.

</details>

<details>
<summary><strong>Can I use the app without creating an account?</strong></summary>

Yes. A ZEROCHILL account is optional for basic browsing. Account-based social features require sign-in.

</details>

<details>
<summary><strong>Does ZEROCHILL have an advertising network?</strong></summary>

The project privacy notice states that the app does not include its own advertising network. Connected websites and third-party services may have their own advertising and privacy practices.

</details>

<details>
<summary><strong>Can I restore my local data on another phone?</strong></summary>

Use the built-in backup and restore tools for compatible local data. Do not assume a backup contains downloaded media files or every account-backed item. Retain your original device and files until you verify the restore.

</details>

<details>
<summary><strong>Where should I get the latest APK?</strong></summary>

Use the [official GitHub Releases page](https://github.com/Addy37/ZEROCHILL/releases/latest) or the app's existing updater. Avoid third-party reuploads.

</details>
