# ZEROCHILL 7.0.5

- Bunkr album search is back through independent Bunkr Index. Queries go directly to that service; existing search fallbacks remain.
- Support ZEROCHILL from the animated OLED dialog with GitHub Sponsors and Cash App.
- Long What's New and update notes now scroll, including with larger text.
- Fixed action-menu crashes when a Downloads row detaches during positioning, plus safer teardown handling.
- Improved Bunkr read-error fallback.

- OnlyHaven's creator/category APIs can intermittently return server errors. Balbums may require browser verification, and EFukt availability varies by region.
