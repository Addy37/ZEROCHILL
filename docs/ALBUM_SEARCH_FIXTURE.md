# Search-bar fixture, not a live provider

This branch starts from main after PR #479, not the discarded separate preview #480. A debug-only Erome chip appears beside Bunkr in the existing native search panel when the local fixture asset is present. The sample file contains invented non-explicit album metadata, not a captured Erome response. Search reuses the existing debounce, cancellation, result list and cache; its footer explicitly identifies local samples. No external URLs, image fetches, resolver calls, analytics, search-history writes or search snapshots originate from the fixture. Tapping a sample identifies it as metadata only; live gallery navigation is not implemented.

Release builds have no fixture asset and keep their existing six search choices. No changes to provider registration, source configuration, Supabase, signing, application ID, other providers, OnlyFap home or ShitTok. The next integration requires a verified authorized search-result sample; this branch does not establish live parsing or playback. New pure unit tests and a native search-scope regression are included. No APK workflow is added; do not merge or publish this fixture branch as a live integration.
